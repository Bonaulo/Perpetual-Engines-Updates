# Android 카드 매니저

게임과 별도로 설치하는 **PE 카드 매니저** 앱이다. Android 8.0 이상에서 사용하며 PC 프로젝트 폴더나 별도 서버가 필요 없다.

## 처음 연결

1. `Perpetual-Engines-Card-Manager.apk`를 휴대폰에서 내려받아 설치한다. Android가 요청하면 다운로드에 사용한 브라우저/파일 앱에 대해 이번 APK 설치를 허용한다.
2. 앱의 **GitHub에서 토큰 만들기**를 누른다.
3. Fine-grained personal access token을 생성한다. Resource owner는 **Bonaulo**, Repository access는 **Only select repositories**로 지정하고 아래 두 저장소를 선택한다.
   - `Perpetual-Engines`: 카드 수치·설명·이미지 원본
   - `Perpetual-Engines-Updates`: 공개 이미지와 다운로드 파일
4. Repository permissions의 **Contents → Read and write**를 지정한다. 계정 자체에도 해당 저장소 쓰기 권한이 있어야 한다.
5. 생성된 토큰을 앱에 붙여넣고 **연결 및 보안 저장**을 누른다. 토큰을 채팅으로 보내지 않아도 된다.

토큰은 Android Keystore 키로 암호화해 앱 내부에 저장한다. 앱 백업은 비활성화되어 있고, APK에는 토큰이 포함되지 않는다. **연결 설정 → 연결 해제·토큰 삭제**로 기기에서 지울 수 있다. 토큰 만료/권한 변경 시 새 토큰을 등록한다.

## 편집

- **새로고침**으로 비공개 소스 저장소 `main`의 최신 카드 목록을 읽는다. 이름/ID와 세력으로 검색한다.
- 카드를 선택해 이미지, 점수·위력·내구·지휘·등급을 수정한다. 카드 종류에 해당하는 수치만 활성화된다.
- **한국어 / 영어 설명**에서 특성·명령·반응을 각각 수정한다. 커맨더는 전체 설명을 편집한다. 줄바꿈은 저장 시 `/`로 합친다. 영어는 자동 번역하지 않는다.
- **휴대폰에 초안 저장**은 원격 파일을 바꾸지 않는다. 카드별로 초안과 선택 이미지가 앱 내부에 남는다. 원격 카드 에셋이 바뀐 초안은 자동 적용하지 않는다.
- **편집 초기화**는 해당 카드의 로컬 초안을 삭제한다.
- 설명 수정은 표시 문구만 바꾼다. 실제 피해량 등 능력 로직은 별도 효과 저작 작업이다.

## 업로드

- **이미지 업로드**: 방향을 보정하고 최대 2048px로 줄여 원본 저장소와 공개 이미지 서버에 올린다. 다른 카드의 이미지 목록은 유지한다. 게임의 다음 이미지 갱신 때 반영된다. 최대 업로드 크기는 4MiB이다.
- 이미지 원본 커밋에는 `[skip ci]`를 붙인다. 앱이 공개 이미지 목록을 직접 갱신하므로 전체 이미지 자동화가 중복 실행되는 것을 막는다. 앱은 업로드 해시를 검증하고 파일과 목록을 하나의 원격 커밋으로 공개한다.
- **수치·설명 업로드**: 변경 내역 확인 후 카드 에셋, 해당 한·영 목록, 재생성 데이터 및 한국어 번역을 함께 원격에 반영한다. 기존 Windows/Android 자동 빌드·배포가 시작된다. 배포 PC가 켜져 있어야 하며 **업로드 완료는 게임 빌드 완료가 아니다.**
- **게임 배포 상태**에서 Actions를 확인한다. 앱을 다시 빌드하지 않아도 카드 매니저는 이후 갱신된 카드 데이터를 읽는다.
- 원격 충돌이 발생하면 초안을 확인한 뒤 목록을 새로고침한다. 앱은 강제 푸시하지 않는다. 네트워크가 끊겨 결과가 불명확하면 재시도할 수 있다. 이미지 원본 업로드만 성공한 경우에도 같은 이미지를 재시도한다.
- 모바일에서 수정한 뒤 PC 관리 프로그램을 쓸 때는 먼저 PC 저장소를 GitHub Desktop으로 동기화한다. 휴대폰은 PC의 로컬 파일을 수정하지 않는다. PC에 남은 미커밋 변경도 확인해야 한다.

## 빌드와 검증

소스: `tools/card-manager-android/`. 설치된 Unity의 Android SDK/JDK를 빌드 도구로만 사용하며 게임/Unity 런타임은 APK에 포함하지 않는다. 별도의 앱 ID와 서명키를 사용하므로 게임 설치에 영향을 주지 않는다.

```
python tools/test_card_manager_android.py
python tools/build_card_manager_android.py
python tools/verify_card_manager_android.py
```

관리 앱 서명키는 사용자 홈의 `.perpetual-engines/card-manager-signing/`에 보관한다. 이후 업데이트를 같은 앱으로 설치하려면 이 키를 유지해야 한다. 키와 비밀번호는 Git이나 공개 저장소에 올리지 않는다.

검증: 실제 에셋 126장에 대한 148개 데이터 검사, 6개 원격 업로드 시뮬레이션, Java/Dex 컴파일, APK 서명·권한·패키지·정렬 검증. 테스트는 실제 카드 수치를 변경하거나 테스트용 게임 업데이트를 배포하지 않는다. 연결된 Android 기기와 에뮬레이터가 없어 설치·터치 화면·기기 Keystore·실제 인증 업로드는 미검증이다.
